# LeetCode Solutions (Python)

A daily log of my Python solutions to Data Structures and Algorithms (DSA) problems from [LeetCode](https://leetcode.com/). This repository is actively updated as I practice and solve new problems every day.

## Repository Structure

All solutions are written in **Python** and follow the naming convention: `<Problem-Number>-<Problem-Title>.py`.

## Topics Covered

* **Arrays & Hashing:** Two Sum, 3Sum, Spiral Matrix, Merge Intervals, Sort Colors, Find Pivot Index
* **Two Pointers & Sliding Window:** Longest Substring Without Repeating Characters, Remove Duplicates, Backspace String Compare
* **Linked Lists:** Add Two Numbers, Merge Two Sorted Lists, Linked List Cycle, Reverse Linked List, Design Linked List
* **Stacks & Queues:** Valid Parentheses, Min Stack, Basic Calculator, Implement Queue using Stacks, Next Greater Element I
* **Trees & Binary Search Trees:** Binary Tree Traversals & Construction, Validate BST, Unique BSTs, Convert Sorted Array/List to BST
* **Dynamic Programming & Math:** Triangle, Best Time to Buy and Sell Stock, K Inverse Pairs Array, Fibonacci/Tribonacci, Count Primes, Sqrt(x)
